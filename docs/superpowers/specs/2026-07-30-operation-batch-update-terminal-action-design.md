# 运控批次修改终态按钮语义

## 目标

批次修改确认弹窗中的左侧按钮必须准确表达当前可执行动作，避免已完成的任务仍显示“取消”。

## 规则

- 修改预览阶段和执行中：显示“取消”。
- 修改任务进入任意 `completed` 终态后：显示“关闭”。
- “关闭”只关闭弹窗，不改变已经完成的运控任务。
- 再次生成新的修改预览时：按钮恢复为“取消”。
- 右侧确认按钮、修改执行流程和服务端状态不做调整。

## 实现范围

只调整批次修改确认弹窗的按钮渲染，并增加回归测试覆盖未完成、已完成和重新预览三种状态。

## 验收

1. 新预览和执行中的左侧按钮为“取消”。
2. `completed` 后左侧按钮自动变为“关闭”。
3. 完成后重新打开新预览，左侧按钮重新显示“取消”。
4. 相关测试与项目全量测试通过。
